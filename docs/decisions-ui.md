# UI stream decisions

Decisions taken by the UI stream (`desktop/stopmotion/ui/`, `settings.py`,
`__main__.py`, `desktop/tests/test_ui.py`) while the user was away.

| area | roadblock | decision | rationale |
|---|---|---|---|
| Capture shortcut | "Global keyboard shortcut" is impossible to take over system-wide from inside a Qt app, and a bare `Return` bound application-wide would swallow Enter in every line edit and dialog. | `Ctrl+Return` and `F5` are `ApplicationShortcut`s; a bare `Return`/`Enter` also captures when the viewport has focus (the normal shooting state). The big CAPTURE button sits in the transport bar under the image. | Covers both a keyboard at the set and a cheap BT remote that sends Enter, without breaking text entry. |
| Bandwidth readout | `PhoneConnection` decodes JPEG on the IO thread and only `QImage`s cross the signal boundary, so the UI never sees the encoded byte count, and the contract exposes no counter. | Estimate from the decoded frame area at 0.15 bytes/pixel and prefix the readout with `≈`. If a `bytes_received` int attribute ever appears on `PhoneConnection`, the readout switches to the exact value and drops the `≈` automatically. | Honest about being an estimate, still useful for spotting a stream that has collapsed, and costs nothing when the real counter lands. |
| Saving the manifest | `TimelineCommand` "marks the project dirty" but nothing in the contract says who writes `project.json`. | `MainWindow.timeline_changed()` calls `Project.save()` after every command. | Saves are atomic (tmp + `os.replace`) and cheap; a duplicate save from `commands.py` would be harmless, a missing one would lose frames. |
| TimelineContext surface | The protocol lists only `project` / `selection()` / `set_selection()` / `timeline_changed()`, but the base command class might also want a dirty hook. | `MainWindow` additionally exposes `dirty`, `mark_dirty()` and `set_dirty()`. | Defensive superset; costs three lines, avoids an AttributeError if the command base grows one. |
| Crop at project creation | The real capture resolution is only known once the first still arrives, but `Project.create()` needs a crop up front. | Create the crop from `CameraCapabilities.sensor_size` (or 4032×3024 when offline), then reconcile it against the actual size on the first `CAPTURE_RESULT` via `Crop.for_aspect(...)`. | The aspect the user picked is what matters; the pixel rectangle is derived. |
| Crop reconciliation is not undoable | It is a project property, not a timeline edit, so it has no place on the frame command stack. | `_reconcile_crop()` assigns `project.crop` / `project.capture_size` directly and saves. | The undo stack is for the timeline; putting a one-time geometry fix on it would confuse "undo" for the user. |
| Filmstrip widget | `QListView`/`QListWidget` gives roughly the right selection behaviour but fights every other requirement (hatched hidden frames, index+duration captions, dragging a *multi* selection, no direct mutation). | Custom `QAbstractScrollArea` with its own painting, hit-testing and drag handling. `handle_click(index, modifiers)` is public. | Full control, and the selection model is testable without synthetic mouse events. |
| Dragging a multi-selection | A plain left click normally collapses the selection to one frame, which would destroy a multi-frame drag before it starts. | A plain press on a frame that is already part of a multi-selection defers the collapse to mouse *release*; if the press turned into a drag, the selection survives and is reordered. | Matches how every file manager behaves; plain/shift/ctrl semantics are otherwise exactly as specified. |
| SHIFT+CTRL+click | Not covered by the specification. | Union: the shift range is added to the existing selection, the anchor is kept. | The least surprising reading, and the only one that composes with the two documented modifiers. |
| Duration editing | Durations are real time (ms) but the model stores integer hold counts. | `set_duration_ms()` converts with `holds = max(1, round(ms * fps / 1000))`; the input dialog steps in whole holds and says so in its label. | Keeps the model integral while the user thinks in ms, as the plan asks. |
| Onion anchor with one frame selected | Ambiguous whether "follows the selection" means the selected frame or the one before it. | The selected frame itself is the nearest (most opaque) layer; depth 2 and 3 are the visible frames before it. | You line the next shot up *against* the frame you are looking at. With nothing or several frames selected the anchor is the last visible frame, as specified. |
| Onion layer opacity | Only one opacity value is exposed to the user, but three layers can be shown. | Slider value × a fixed falloff of 1.0 / 0.6 / 0.38 for layers 1 / 2 / 3. | "Nearer frames more opaque" with one control instead of three. |
| Review playback timing | Sub-frame-accurate scheduling would need a monotonic clock loop. | A `QTimer` at `1000/fps` ms, one tick per hold unit, hidden frames excluded from the tick list. | At 1–30 fps the jitter is invisible, and review is for judging motion, not for mastering. |
| Export resolutions | A free width/height pair invites non-even numbers that break yuv420p. | Fixed heights (720p / 1080p / 1440p / 2160p, default 1080p), width derived from the crop aspect and rounded to an even number. | One control, always a legal H.264 size. |
| Export quality | `ExportSettings` takes crf + x264 preset; users do not think in crf. | Four presets: Draft (26/veryfast), Good (21/medium), High (18/medium, default), Archive (14/slow). | Named choices, the contract's numbers underneath. |
| "Launch the phone app" offer | Offering it on the very first failed connect would flash the button during the normal startup race. | The banner grows a *Launch phone app* button only once a device is attached **and** at least two connection attempts have failed; it calls `DeviceManager.launch_app()`. | Avoids a flapping UI while still catching "phone plugged in, app not running". |
| Auto-reconnect | Nothing in the contract drives reconnection. | A 4 s timer re-runs `adb forward` and `PhoneConnection.start()` while disconnected (fake mode skips the adb part). `start()` is a no-op when a thread already exists, so the timer is safe. | Verified live: the app reconnects ~1 tick after the phone reappears. |
| Settings on reconnect | The desktop is the source of truth. | Every HELLO re-pushes the settings the desktop holds (restored from QSettings at startup, clamped to the new capabilities) instead of adopting device defaults. | Verified live: a hand-set ISO of 1234 was re-sent verbatim after killing and restarting the phone. |
| Preferences storage | No storage mechanism was specified. | `QSettings` (INI, org `kruse`, app `stopmotion`) behind a typed `AppSettings` wrapper: recent projects, camera settings, onion/crop/loop prefs, export defaults, window geometry. Tests redirect `QSettings` to a temp dir. | Standard Qt, no new dependency, and tests never touch the real user config. |
| Tests without pytest-qt | pytest-qt is not installed and may not be added. | A session-scoped `QApplication` fixture built by hand; widgets are driven through their own public methods (`handle_click`, `_on_hello`, `_on_capture_result`, …) and `QWidget.grab()` exercises every `paintEvent`. | 30 headless tests, no new dependency. |
| `desktop/stopmotion/__init__.py` | Not in this stream's ownership list, and `python -m stopmotion` needs `desktop/` on `sys.path`. | Left alone. Another stream created it plus a `stopmotion-dev.pth` in the venv, so `python -m stopmotion` works from the repo root; `test_ui.py` inserts `desktop/` into `sys.path` itself so it does not depend on that. | Stay inside the file ownership boundary. |
| Observed instability (not mine to fix) | Once, killing the fake phone process at the same moment the window closed produced `QSocketNotifier: Socket notifiers cannot be enabled or disabled from another thread` and a core dump during interpreter teardown. | Logged, not worked around; it is in `connection.py`'s worker-thread shutdown (stream B). Did not reproduce on repeat runs, and normal quits exit 0. | Editing another stream's file was out of scope; worth a look if it ever shows up interactively. |

## Contract deviations

None. Every module this stream consumes matched `docs/interfaces.md`. Three
implementations turned out to be supersets of the contract, and only the
contracted surface is used:

| module | superset |
|---|---|
| `connection.py` | `PhoneConnection(port, parent, host=…, capture_timeout=…)`, `request_capture(timeout=None)`, an `is_connected` property |
| `project.py` | `Project.create(..., crop: Crop \| str \| None)`, `Frame.width/height/missing`, `frame_by_id()`, `insert_frame()`, `remove_frame()` |
| `export.py` | `Exporter.is_running()`, `Exporter.wait()` |

`Project.index_of()` returns `-1` for an unknown id rather than raising; the
onion-skin anchor logic treats a negative index as "no anchor".
