I want to have a camera setup that connects my Android phone to a stopmotion desktop application.

I want the desktop application to handle setting the camera options (like blend time, focus, etc) and triggering a snapshot.
A real time preview should be displayed in the application.

The image should not be stored on the phone but instead directly transferred to the computer and be inserted as the latest image in a stopmotion movie.
In the desktop application I want to be able to use the standard playback features and edit the duration of each frame.
The finished movie should be able to be saved as a video file on the computer.
